# Vanilla + DaisyUI + Tailwind

This is just a simplified page with a single button dead center!

How this was setup:

```shell
npm create vite@latest web
cd web/
npm i
npm install tailwindcss @tailwindcss/vite daisyui
touch vite.config.js # and setup tailwind
npm run dev
```

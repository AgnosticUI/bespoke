# Vue 3 + TypeScript + AgnosticUI

This is just a simplified page with a single button dead center!

How this was setup:

```shell
 npm create vite@latest
 cd agnosticui-verify/
 npm i
 npx agnosticui-cli init
 npx agnosticui-cli add button
 npm run dev
```

More AgnosticUI docs at: https://www.agnosticui.com/installation.html
